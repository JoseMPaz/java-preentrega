\section{Creación del proyecto}
El proyecto por problemas velocidad del ordenador lo realice desde la terminal de linux. Para crear un nuevo proyecto java en desde la terminal creo un script build\_new\_proyect.sh el cual crea las carpeta como lo necesita maven, crea las carpetas ui, util, model, exception y service. Tambien crea un Main.java con un Hola mundo de prueba.

\subsection{build\_new\_proyect.sh}
\lstinputlisting[caption={Script de automatización build\_new\_proyect.sh}, label={code:script_bash}]{build_new_proyect.sh}

Este script debe tener permiso de ejecución que se otorga del siguiente modo:\\
\textbf{chmod +x build\_new\_proyect.sh}\\ 

Luego se ejecutó para crear el proyecto como se muestra en la \autoref{figura:nuevo_proyecto_java}.

\end{figure}
